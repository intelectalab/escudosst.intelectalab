# 14 · Glosario

## Términos de SST y normativa

| Término | Significado |
|---|---|
| SST | Seguridad y Salud en el Trabajo |
| SG-SST | Sistema de Gestión de Seguridad y Salud en el Trabajo |
| Ley 29783 | Ley de Seguridad y Salud en el Trabajo del Perú |
| Reglamento | D.S. 005-2012-TR, reglamento de la Ley 29783 |
| R.M. 050-2013-TR | Resolución que aprueba los formatos referenciales de los registros obligatorios y la guía de línea base |
| Línea base | Diagnóstico inicial del estado del SG-SST frente a la ley |
| Política SST | Declaración firmada por el empleador con sus compromisos en SST |
| Plan Anual SST | Documento con objetivos, metas y recursos del año |
| PASST | Programa Anual de Seguridad y Salud en el Trabajo: actividades, responsables, fechas y avance |
| PCA | Programa anual de capacitación (en el producto, módulo PCA) |
| Comité SST | Órgano paritario (empleador y trabajadores) obligatorio desde 20 trabajadores |
| Supervisor SST | Trabajador elegido para las funciones del comité en empresas con menos de 20 trabajadores |
| RISST | Reglamento Interno de Seguridad y Salud en el Trabajo (obligatorio desde 20 trabajadores) |
| IPERC | Identificación de Peligros, Evaluación de Riesgos y medidas de Control |
| Peligro | Fuente con potencial de causar daño |
| Riesgo | Probabilidad de que el peligro cause daño, combinada con su severidad |
| Riesgo residual | Riesgo que queda después de aplicar controles |
| Jerarquía de controles | Eliminación, sustitución, ingeniería, administrativos, EPP (en ese orden) |
| Mapa de riesgos | Plano del centro de trabajo con los riesgos señalados con pictogramas |
| Agentes | Factores físicos, químicos, biológicos, disergonómicos y psicosociales que se monitorean |
| LMP / VLP | Límite máximo permisible / valor límite permisible de exposición |
| PETS | Procedimiento Escrito de Trabajo Seguro |
| PETAR | Permiso Escrito de Trabajo de Alto Riesgo (altura, caliente, espacio confinado, eléctrico, etc.) |
| ATS | Análisis de Trabajo Seguro, hecho antes de iniciar una tarea |
| Charla de 5 minutos | Charla breve de seguridad antes de la jornada |
| Acto subestándar | Acción de una persona que puede causar un accidente |
| Condición subestándar | Situación del entorno que puede causar un accidente |
| Observación de conducta | Seguridad basada en el comportamiento: observar y retroalimentar conductas |
| EPP | Equipo de Protección Personal |
| Accidente de trabajo | Suceso repentino por causa o con ocasión del trabajo que produce lesión, invalidez o muerte |
| Accidente leve / incapacitante / mortal | Clasificación por gravedad según el reglamento |
| Incidente | Suceso en el trabajo sin lesión |
| Incidente peligroso | Suceso con alto potencial de causar lesiones graves o daños a la población |
| Enfermedad ocupacional | Enfermedad contraída por la exposición a factores de riesgo del trabajo |
| Árbol de causas | Método de investigación que reconstruye la cadena de hechos de un accidente |
| SCAT | Systematic Cause Analysis Technique: técnica de análisis sistemático de causas |
| Acción correctiva | Acción para eliminar la causa de un problema detectado |
| Índice de frecuencia (IF) | Accidentes incapacitantes por un millón (u otro factor) de horas-hombre trabajadas |
| Índice de gravedad (IG) | Días perdidos por un millón (u otro factor) de horas-hombre |
| Índice de accidentabilidad (IA) | IF × IG / 1000 |
| Horas-hombre | Horas trabajadas por todos los trabajadores en un periodo |
| EMO | Examen Médico Ocupacional: de ingreso (preocupacional), periódico y de retiro |
| Aptitud | Resultado del EMO: apto, apto con restricciones, no apto |
| Vigilancia médica | Seguimiento de la salud de los trabajadores expuestos a riesgos |
| Descanso médico | Incapacidad temporal para trabajar certificada por un médico |
| Grupos vulnerables | Gestantes, adolescentes, personas con discapacidad y otros con protección especial |
| SCTR | Seguro Complementario de Trabajo de Riesgo (salud y pensiones) |
| Contratista | Empresa que presta servicios en las instalaciones del cliente |
| Acreditación | Aprobación de un contratista tras verificar sus documentos y los de sus trabajadores |
| Homologación | Evaluación y calificación de proveedores |
| Revisión por la dirección | Evaluación periódica del SG-SST por la alta dirección |
| Auditoría del SG-SST | Evaluación del sistema por un auditor registrado en el MTPE |
| 9 registros | Registros obligatorios del art. 33 del reglamento presentados en 9 formatos |
| SSOMA | Seguridad, Salud Ocupacional y Medio Ambiente |
| ISO 45001 | Norma internacional de sistemas de gestión de SST |
| MOC | Management of Change: gestión del cambio |
| Libro de Reclamaciones | Registro (físico o virtual) en el que el consumidor deja un reclamo o queja ante el proveedor (Ley 29571, D.S. 011-2011-PCM y modificatorias). En EscudoSST lo publica el sitio web (WEB) |
| Reclamo / queja | Reclamo: disconformidad con el producto o servicio. Queja: malestar respecto de la atención. Tipos de la hoja de reclamación |
| Hoja de reclamación | Cada registro del Libro de Reclamaciones, con código correlativo, constancia y plazo de respuesta (`consumer_complaints`) |
| Línea de mando | Cadena de jefes responsables de la seguridad de su personal |

## Términos del producto y técnicos

| Término | Significado |
|---|---|
| EscudoSST | Nombre del producto |
| WEB | Módulo interno 1.10: sitio web público de venta y su CMS, administrado por el Dueño de la plataforma |
| CMS | Gestor de contenidos: panel para editar páginas, marca, menú y textos sin tocar código |
| Bloque | Sección reutilizable de una página del sitio (héroe, video, módulo con maqueta, planes, testimonios, CTA…) guardada en `site_pages.blocks_json` |
| Maqueta | Imagen ilustrativa de una pantalla del producto, con datos ficticios, usada en el sitio |
| Re-aceptación | Obligación de aceptar de nuevo una política cuando se publica una versión que lo exige; queda en `legal_acceptances` |
| SEO | Optimización para buscadores: metadatos, sitemap, robots, datos estructurados, canónicas |
| Sitemap / robots.txt | Archivos que indican a los buscadores qué páginas indexar y cuáles no |
| Datos estructurados (JSON-LD) | Marcado que describe la página a los buscadores (Organization, Product/Offer, FAQPage, BreadcrumbList) |
| URL canónica | Dirección preferida de una página cuando hay varias que la muestran |
| Redirección 301 | Redirección permanente de una URL antigua a la nueva |
| SSR / ISR | Renderizado en servidor / regeneración estática incremental en Next.js |
| Core Web Vitals | Métricas de experiencia de carga e interacción (LCP, INP, CLS) usadas como criterio de aceptación del sitio |
| Testimonio | Comentario de un cliente publicado en el sitio con su consentimiento y aprobación del dueño (`site_testimonials`) |
| Sello de confianza | Distintivo de seguridad o cumplimiento mostrado en el sitio; solo si es verdadero y verificado |
| Solicitud de demo | Pedido de demostración, contacto o cotización enviado desde el sitio (`demo_requests`) |
| Cuenta (`account`) | Suscriptor que contrata; puede tener varias empresas |
| Empresa (`company`) | Empleador con RUC; unidad de aislamiento de datos |
| Sede (`site`) | Local, planta, obra o tienda de una empresa |
| Membresía | Relación usuario–empresa con un rol |
| Alcance (`scope`) | Límite de una membresía a sedes o áreas |
| Plan | Esencial, Profesional, Corporativo (acumulativos) |
| Complemento | Módulo contratable aparte con cualquier plan |
| Plan Consultora | Plan para consultoras SST que gestionan varias empresas |
| Marca blanca | La consultora usa su logo, colores y dominio |
| Feature flag | Interruptor por empresa que habilita, bloquea o deja en solo lectura un módulo |
| Solo lectura | Estado de un módulo tras bajar de plan: se ve, no se edita, no se borra |
| Módulo activable por empresa | AUL o VTA: incluido en el plan Profesional, pero cada empresa decide si lo usa (`disabled_by_company` cuando lo desactiva). VTA viene desactivado |
| Aula virtual (AUL) | Portal propio de cursos de EscudoSST dentro del plan Profesional; no depende de otra plataforma |
| Curso | Unidad del aula con secciones, contenidos, participantes, calificaciones, evaluaciones y configuración; acredita un tema de CAP |
| Sección | Agrupación de contenidos dentro de un curso |
| Contenido / actividad | Elemento de una sección: texto, video (Vimeo), documento, enlace o evaluación |
| Recorrido secuencial | Configuración que desbloquea cada actividad obligatoria solo al completar la anterior |
| Banco de preguntas | Conjunto de preguntas general (reutilizable) o de un curso, importable desde Excel |
| Preguntas al azar | Sorteo de un número de preguntas de uno o varios bancos para cada intento |
| Escala de calificación | Forma de calificar de un curso: 0-20, 0-10, 0-100 o por letras (AD/A/B/C, A/B/C/D) |
| Capacitador | Rol `trainer`: dicta y gestiona los cursos que se le asignan según sus permisos configurables |
| Disponibilidad del capacitador | Horario semanal que registra el capacitador para programar sesiones y tutorías |
| Compromiso de culminación | Declaración del participante de terminar el curso; obligatoria si el curso la activa |
| Tiempo de permanencia | Tiempo activo real en el curso, medido por latidos con interacción; no cuenta el tiempo con la ventana abierta sin actividad |
| Latido (`heartbeat`) | Señal periódica del reproductor del curso que el servidor valida para sumar permanencia |
| Matrícula | Inscripción de un participante en un curso (manual, por cargo, por compra o por cupo) |
| Matriz de capacitación por cargo | Temas obligatorios que exige cada puesto, con momento, plazo y vigencia; base del cumplimiento por trabajador |
| Certificado | Documento de aprobación de una capacitación o curso, con código, QR y plantilla; puede requerir validación del administrador |
| Validación del certificado | Aprobación del administrador antes de que el certificado sea descargable y verificable |
| Anulación del certificado | Baja con motivo de un certificado; no se borra y la verificación pública muestra «anulado» |
| Verificación pública por código | Página sin sesión para comprobar un certificado con su código o QR; activable por empresa y por curso |
| Recomendación de curso | Sugerencia de un curso a una persona, cargo, área o empresa compradora, por regla, manual o por IA aprobada; se mide su conversión |
| Regla de recomendación | Criterio automático: brecha por cargo, certificado por vencer, ruta, complementario, hallazgo o accidente del área, perfil similar |
| Conversión | Matrícula o compra atribuida a una recomendación vista o con clic |
| Recomendados para ti | Bloque del portal, la app y el catálogo público con las recomendaciones de la persona |
| Venta de cursos (VTA) | Módulo para que una empresa venda sus cursos con precio definido por la empresa |
| Oferta | Publicación de venta de un curso: precio definido por la empresa, aforo, vigencia y política de reembolso |
| Catálogo público | Vitrina sin sesión de los cursos a la venta de una empresa |
| Cupón | Código de descuento con vigencia y límites de uso |
| Pedido | Carrito confirmado con sus líneas, totales y estado de pago |
| Pasarela de pagos | Proveedor que cobra con tarjeta o Yape (Culqi, Niubiz, Izipay o Mercado Pago; por definir) detrás de `PaymentGateway` |
| Token de pago | Identificador de un solo uso que entrega la pasarela en lugar de los datos de tarjeta |
| Webhook firmado | Aviso de la pasarela al servidor con firma verificable; se procesa una sola vez |
| Conciliación | Contraste entre pedidos, transacciones de la pasarela y comprobantes |
| Matrícula manual | Matrícula por un pago hecho fuera de la pasarela, registrada con evidencia |
| Cupo (licencia) | Derecho de matrícula comprado por una empresa compradora para asignarlo a una persona |
| Empresa compradora | Empresa que compra cupos de cursos a la empresa vendedora |
| Participante externo | Rol `external_learner`: persona que no es trabajador de la empresa y compra o recibe un curso |
| Comprobante electrónico | Boleta, factura o nota de crédito emitida por la empresa vendedora mediante un proveedor por definir |
| Reembolso | Devolución total o parcial de un cobro, con nota de crédito |
| Vimeo | Servicio donde se alojan los videos del aula (detrás de `VideoProvider`) |
| Moodle | Plataforma de cursos externa con la que una empresa puede conectarse de forma opcional (`LmsProvider`) |
| Fotocheck | Credencial del trabajador; en EscudoSST con QR verificable |
| Modo SUNAFIL | Módulo que prepara el expediente para una inspección |
| Expediente | Conjunto de evidencias por trabajador, periodo y materia |
| Punto de reporte | Lugar físico con un QR para reportar actos y condiciones |
| Paquete sectorial | Plantillas y formatos para un sector (PSE) |
| Parámetro legal | Valor normativo con vigencia y marca `to_confirm` |
| PWA | Progressive Web App: aplicación web instalable que funciona offline |
| IndexedDB | Base de datos del navegador usada por la PWA |
| Lote de sincronización | Conjunto de operaciones offline enviado al servidor |
| Idempotencia | Propiedad de una operación que, repetida, produce el mismo resultado |
| `idempotency_key` | Identificador único de una operación para evitar duplicados |
| Conflicto | Cambio offline sobre un registro que cambió en el servidor |
| RLS | Row-Level Security: seguridad a nivel de fila de PostgreSQL |
| FK compuesta | Clave foránea que incluye `company_id` para impedir cruces entre empresas |
| Tabla inalterable | Tabla que solo acepta inserciones |
| Re-autenticación | Pedir de nuevo una clave o MFA antes de mostrar datos médicos |
| `sensitive_access_logs` | Registro de cada acceso a datos sensibles |
| Base principal | `escudo_main` en Contabo |
| Base médica | `escudo_medical` en DigitalOcean |
| `fitness_status` | Aptitud médica no sensible guardada en la base principal |
| SSE-B2 | Cifrado del lado del servidor de Backblaze B2 |
| URL firmada | Enlace temporal con firma que permite subir o descargar un archivo |
| LUKS | Cifrado de disco en Linux |
| BSP | Business Solution Provider: proveedor autorizado de WhatsApp Business API |
| MFA | Autenticación multifactor |
| ARCO | Derechos de Acceso, Rectificación, Cancelación y Oposición |
| Encargado de tratamiento | Quien trata datos personales por cuenta del titular del banco de datos |
| Flujo transfronterizo | Transferencia de datos personales fuera del Perú |
| `RN-*` | Identificador de regla de negocio en `docs/modulos` |
| `SCR-<COD>-NN` | Identificador de pantalla |
| `ESC-*` | Identificador de historia del backlog |
| `P-NN` | Identificador de parámetro legal (`11`) |
| `DA-NN` | Identificador de decisión abierta (`13`) |
